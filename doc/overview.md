# Introduction

The ctrlX AUTOMATION SDK is the Software Development Kit of [ctrlX AUTOMATION](https://www.ctrlx-automation.com).
With this SDK, software applications (apps) can be developed in various high-level languages for the Linux-based ctrlX AUTOMATION CORE devices.

You can find a short introduction to ctrlX AUTOMATION here: [ctrlX AUTOMATION](ctrlx_automation.md).
