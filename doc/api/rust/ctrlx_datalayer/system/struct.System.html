Struct System

pub struct System { /* private fields */ }
Expand description

Represents a ctrlX Data Layer system instance.

The System is the root object of the Data Layer. It manages the lifecycle of the underlying native system handle and provides access to the factory and converter subsystems.

ⓘ
let system = System::new("");
system.start(false);
{
  ...
}
info!("Shutdown!");
