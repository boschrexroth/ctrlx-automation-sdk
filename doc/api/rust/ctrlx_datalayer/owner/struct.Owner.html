Struct Owner

pub struct Owner { /* private fields */ }
Expand description

Represents the owner of a shared memory area.

An Owner creates and controls a shared memory that can be read by one or more Users. It can define the memory layout via the memory map and grants safe, scoped read/write access through an AccessGuard.

§Example

let system = System::new("");
let provider = system.factory().create_provider(ctrlx_datalayer::factory::Connection::Ipc);
let factory = system.factory();
let mut owner = factory.create_memory("sdk/rust/shared", &provider, 1024, ctrlx_datalayer::memory_type::MemoryType::Input)?;

println!("created memory of {} bytes", owner.size_of_memory()?);

// Write into the shared memory within a scoped guard.
{
    let mut guard = owner.access_guard(0)?;
    let data = guard.as_slice();
    data[0] = 42;
} // access is released here

pub fn set_memory_map(&self, memory_map: &MemoryMapT) -> Result<(), Result>

Sets the memory map that describes the layout of the shared memory.

The memory map defines which variables live in the shared memory and where they are located (bit offset, bit size, type). The provided [MemoryMapT] is serialized to flatbuffers internally and applied to the owned memory.

§Arguments
  • memory_map - The memory map describing the variables and their layout within the shared memory.
§Example
use ctrlx_fbs::memory_map_generated::{MemoryMapT, VariableT};

// Describe a single 32-bit integer variable at bit offset 0.
let mut variable = VariableT::default();
variable.name = "myInt".to_string();
variable.bitoffset = 0;
variable.bitsize = 32;
variable.type_ = Some("int32".to_string());

let mut memory_map = MemoryMapT::default();
memory_map.variables = Some(vec![variable]);
memory_map.revision = 1;

owner.set_memory_map(&memory_map)?;

pub fn memory_map(&self) -> Result<MemoryMapT, Result>

Returns the memory map describing the layout of the shared memory.

The memory map lists all variables stored in the shared memory together with their bit offsets, sizes and types.

§Example
let map = owner.memory_map()?;
if let Some(ref variables) = map.variables {
    for variable in variables {
        println!("variable at bit offset {}", variable.bitoffset);
    }
}

pub fn access_guard(&mut self, revision: u32) -> Result<AccessGuard<'_>, Result>

Begins a scoped read/write access to the shared memory.

Returns an AccessGuard that provides a mutable view of the memory. The access is automatically released when the guard goes out of scope.

§Arguments
  • revision - The expected memory map revision. Use 0 to accept the current revision.
§Example
{
    let mut guard = owner.access_guard(0)?;
    let data = guard.as_slice();
    data[0] = 42; // write directly into shared memory
} // access is released here
