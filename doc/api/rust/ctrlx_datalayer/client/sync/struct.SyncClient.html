Struct SyncClient 

Source 
pub struct SyncClient { /* private fields */ }
Expand description

Provides synchronous access to the Data Layer.

A SyncClient is obtained via Client::sync. It holds the same DLR_CLIENT handle as the owning Client and is dropped automatically when the Client is dropped.

pub fn read_json( &self, cv: &Converter, address: &str, indent_step: i32, data: Option<&[u8]>, ) -> Result<Value, Result>

Reads the value at the given Data Layer address and returns it as a JSON-encoded variant.

§Arguments
  • cv - The Converter used to serialize the result to JSON.
  • address - The Data Layer address to read from.
  • indent_step - Number of spaces used for JSON indentation. Use -1 for compact output.
  • data - Optional input argument passed to the node as a JSON byte slice.
§Errors

Returns crate::Result if the read or JSON conversion fails.

ⓘ
let converter = system.converter();
let sync_client = client.sync();
let json_value = sync_client.read_json(&converter, "some/address", 2, None).expect("Read JSON failed");

pub fn write_json( &self, cv: &Converter, address: &str, json: &[u8], ) -> Result<(), ConverterResult>

Writes a JSON-encoded value to the given Data Layer address.

The json byte slice is parsed using the provided converter before the write is performed.

§Arguments
  • cv - The Converter used to deserialize the JSON input.
  • address - The Data Layer address to write to.
  • json - The value to write, encoded as a UTF-8 JSON byte slice.
§Errors

Returns ConverterResult::CommonFailed containing the error code and an error message if the write or JSON parsing fails.

ⓘ
let converter = system.converter();
let sync_client = client.sync();
sync_client.write_json(&converter, "some/address", br#"{"key": "value"}"#).expect("Write JSON failed");
