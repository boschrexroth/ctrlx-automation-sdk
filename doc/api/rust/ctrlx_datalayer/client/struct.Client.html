Struct Client 

Source 
pub struct Client { /* private fields */ }
Expand description

Represents a Data Layer client connection.

A Client is created via Factory::create_client and provides read/write access to nodes in the Data Layer.

Returns a reference to the SyncClient.

The SyncClient is created lazily on the first call and lives as long as this Client instance. It shares the same underlying DLR_CLIENT handle.
