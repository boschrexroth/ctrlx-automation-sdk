Struct Converter

pub struct Converter { /* private fields */ }
Expand description

Provides JSON conversion capabilities for Data Layer variant values.

The Converter is obtained from a System and wraps the native JSON converter handle. It can be used to serialize and deserialize Data Layer variants to and from their JSON representation.

pub fn generate_json_simple( &self, data: &Value, indent_step: i32, ) -> Result<Vec<u8>, Result>

Serializes a simple (scalar) Data Layer variant to its JSON byte representation.

§Arguments
  • data - The variant value to serialize.
  • indent_step - Number of spaces used for JSON indentation. Use 0 for compact output.
§Errors

Returns crate::Result if the serialization fails.

§Examples
use ctrlx_datalayer::system::System;

let system = System::new("");
system.start(true);

let converter = system.converter();
let data = ctrlx_datalayer::Value::new(42i32);
let json = converter.generate_json_simple(&data, -1).unwrap();

assert_eq!(
    String::from_utf8(json).unwrap(),
    r#"{"type":"int32","value":42}"#
);

pub fn generate_json_complex( &self, data: Vec<u8>, ty: Vec<u8>, indent_step: i32, ) -> Result<Vec<u8>, Result>

Serializes a complex (FlatBuffers-encoded) Data Layer variant together with its type information to a JSON byte representation.

§Arguments
  • data - The FlatBuffers-encoded variant data.
  • ty - The FlatBuffers-encoded type descriptor.
  • indent_step - Number of spaces used for JSON indentation. Use 0 for compact output.
§Errors

Returns crate::Result if the serialization fails.

§Examples
use ctrlx_datalayer::system::System;
use ctrlx_datalayer::Schema;

let system = System::new("");
system.start(true);

let converter = system.converter();

// Use the Memory schema as data and the Reflection schema as its type descriptor.
let data = converter.schema(Schema::Memory).unwrap();
let ty = converter.schema(Schema::Reflection).unwrap();

let json = converter.generate_json_complex(data, ty, -1).unwrap();
assert!(!json.is_empty());

pub fn parse_json_complex( &self, json: Vec<u8>, ty: Vec<u8>, ) -> Result<Vec<u8>, ConverterResult>

Deserializes a complex JSON byte vector using the provided FlatBuffers type descriptor into a FlatBuffers-encoded variant value.

§Arguments
  • json - The JSON bytes to parse.
  • ty - The FlatBuffers-encoded type descriptor that describes the expected structure.
§Errors

Returns ConverterResult::ParseJsonComplexFailed containing the error code and an error message if parsing fails.

§Examples
use ctrlx_datalayer::system::System;
use ctrlx_datalayer::Schema;

let system = System::new("");
system.start(true);

let converter = system.converter();

// Serialize the Memory schema to JSON, then parse it back using the Reflection type.
let data = converter.schema(Schema::Memory).unwrap();
let ty = converter.schema(Schema::Reflection).unwrap();

let json = converter.generate_json_complex(data, ty.clone(), -1).unwrap();
let parsed = converter.parse_json_complex(json, ty).unwrap();
assert!(!parsed.is_empty());
