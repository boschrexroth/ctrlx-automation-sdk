ctrlx_datalayer::variant::value

Struct Value 

Source 
pub struct Value { /* private fields */ }
Expand description

A type-safe value container for ctrlX Data Layer variants.

Stores an arbitrary value together with its VariantType. The type is automatically derived from the Rust type when creating a value and can be overridden afterwards using setter methods.

§Example

use ctrlx_datalayer::variant::Value;
use ctrlx_datalayer::variant::VariantType;

let v = Value::new(42i32);
assert_eq!(v.variant_type(), VariantType::Int32);
assert_eq!(v.as_ref::<i32>(), Some(&42));
assert_eq!(v.as_ref::<i32>().copied().unwrap(), 42i32);

Hint: For vec! macros or String, you must use ‘cloned’ to get the inner values, e.g. v.as_ref::<Vec<i32>>().cloned().unwrap()

pub fn as_ref<T: 'static>(&self) -> Option<&T>

Returns a reference to the stored value if the type T matches.

Returns None if T does not match the stored type.

§Example
use ctrlx_datalayer::variant::Value;

let v = Value::new(7u8);
assert_eq!(v.as_ref::<u8>(), Some(&7));
assert_eq!(v.as_ref::<u8>().copied().unwrap(), 7u8);
assert_eq!(v.as_ref::<i32>(), None);
let v = Value::new(vec![true, false, true]);
assert_eq!(v.as_ref::<Vec<bool>>(), Some(&vec![true, false, true]));
assert_eq!(v.as_ref::<Vec<bool>>().cloned().unwrap(), vec![true, false, true]);

pub fn timestamp_mut(&mut self, val: DateTime<Utc>)

Sets the value to a DateTime<Utc> (type: VariantType::Timestamp).

The ctrlX Data Layer represents timestamps as FILETIME (100-ns intervals since 1601-01-01 UTC). This setter stores the value as a DateTime<Utc> so it can be retrieved with as_ref::<DateTime<Utc>>().
