# Introduction

To develop ctrlX CORE applications (so-called "Apps") with the ctrlX AUTOMATION SDK, we need the **App Build Environment**, which is an Ubuntu Linux operating system powered by [QEMU](https://www.qemu.org/).

* Setup your [App Build Environment (QEMU VM)](setup_qemu_ctrlx_works.md).

* Alternative Build Environments

    * [VirtualBox Virtual Machine](setup_windows_virtualbox_ubuntu.md) describes how to set up such a VM to use it as an App Build Environment (QEMU VM).
    * [QEMU Virtual Machine](setup_qemu_ubuntu.md) shows how QEMU can be installed as a standalone app and how a QEMU VM can be set up as an App Build Environment (QEMU VM).
    * [Native Ubuntu](setup_ubuntu.md) shows how to set up a bare-metal machine to use it as an App Build Environment (QEMU VM).
    * [Windows Subsystem for Linux (WSL)](https://learn.microsoft.com/en-us/windows/wsl/) with Visual Studio Code Extension [WSL](https://code.visualstudio.com/docs/remote/wsl)

* The [Quick Start Guide](quick-start-guide.md) provides the fastest way to create an app with one of the SDK's sample projects.

* [Install Sources from GitHub](install-sources-from-github.md) describes how to download and install the GitHub repository **ctrlX AUTOMATION Software Development Kit** [https://github.com/boschrexroth/ctrlx-automation-sdk](https://github.com/boschrexroth/ctrlx-automation-sdk)
