# Example ctrlX Data Layer Client

## Introduction

The sample demonstrates how to connect to the __ctrlX Data Layer__ and perform basic operations like ping and browse.

## Function Description

The app connects to the __ctrlX Data Layer__ using a virtual connection.
Performs synchronous/asynchronous ping, browse, and read operations on the Data Layer.

If the __ctrlX Data Layer__ connection breaks the app will exit.
